# @opencawr/core

The **one** OpenCAWR cost engine (spec §8): a pure, framework-agnostic TypeScript function

```ts
costPerMile(vehicle, constants, inputs) → { p50, p75, p90, p05, p95, breakdown, … }
```

Implements the **v2b model** (canonical per owner decision 2026-07-27; full inventory in
the repo-root `ASSUMPTIONS.md`): present-value cost per mile with purchase use tax,
total-loss exposure, a mileage-ramping major-repair tail, a calendar-age upkeep escalator,
data-driven battery risk, per-tier end-of-life dispersion, and deterministic seeded Monte
Carlo. Opportunity cost of capital enters **only** through discounting (spec §2).
`holdMiles` implements the holding horizon (§3); `rankWithTiers` computes beat
probabilities and statistical tie tiers; `feasibility.ts` the two-sided odometer↔year
check (§4).

Requires Node ≥ 20 (`nvm use` / Homebrew `node@22`; tests won't run on Node 16).

## Reference outputs and drift protection

`opencawr_data.json`'s per-vehicle `model_output` is **generated by this engine**
(`npm run gen-reference`, seed/draws recorded in `meta.reference_engine`). The lost
prototype's original numbers are preserved as `model_output_prototype` — historical
context only, never asserted.

- `test/reference.test.ts` — the engine must reproduce `model_output` exactly (rounding
  tolerance only). **Never regenerate the reference to make CI pass**: regeneration is a
  deliberate, reviewed model change.
- `test/determinism.test.ts` — fixed seed ⇒ bit-identical output, forever.

## Launch gate

Reliability inputs in the seed data trace to Consumer Reports and are **not publicly
shippable** until re-derived from NHTSA/CarComplaints/RepairPal (spec §9, ASSUMPTIONS.md).
All outputs are estimates, not advice.
