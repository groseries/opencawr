computes the true lifetime cost-per-mile of owning a used car — bought at a chosen odometer,

**Architecture.** `packages/core` is THE cost engine — one pure `costPerMile(vehicle,
constants, inputs)`, no UI, no I/O. `packages/pipeline` assembles arbitrary vehicles from
EPA/NHTSA with per-field provenance. `apps/web` is Vite+React; all three of its hooks share
ONE Web Worker (`src/sharedWorker.ts`) dispatching on `kind` (rank/deal/survey).

**Hard constraints — these are not negotiable:**

  reproduces every vehicle's stored `model_output` bit-for-bit at seed 42. If a change is
  *supposed* to move the numbers, run `npm run gen-reference -w @opencawr/core` and say so
  explicitly in the commit body. Never regenerate to make a failing test pass.
- **The seed data's `model_output` is a REFERENCE, not truth** — it's generated by our own
  engine; the lost prototype's originals are kept as `model_output_prototype`.
- **Estimates, not advice.** No "good deal / bad deal", no recommendations. Percentiles and
  dollar deltas only.
